# DeepAI Code Persian & RTL Enhancer

افزونه و پچر بهینه‌سازی متن‌های فارسی و راست‌چین (RTL) برای نرم‌افزار دسکتاپ **DeepAI Code**.

---

## 🌟 ویژگی‌ها (Features)

- **حل تداخل متن فارسی و انگلیسی:** جلوگیری از به‌هم‌ریختگی جملات هنگام استفاده هم‌زمان از اصطلاحات انگلیسی، متغیرها و فایل‌ها.
- **ایزولاسیون هوشمند کدهای درون‌خطی (`inline code`):** حفظ جهت طبیعی متغیرها و دستورات با `unicode-bidi: isolate`.
- **حفظ کامل کدهای چندخطی (Code Blocks):** تمامی بلوک‌های کد، دیف‌ها (Diff) و خروجی‌های ترمینال با ساختار استاندارد LTR چپ‌به‌راست و تراز مناسب باقی می‌مانند.
- **فونت یکپارچه وزیرمتن (Vazirmatn):** اصلاح فونت پیش‌فرض و فاصله خطوط برای خوانایی حداکثری متون طولانی.
- **تشخیص داینامیک متن در حال استریم:** اعمال سریع و بهینه راست‌چین روی پیام‌های زنده با استفاده از `MutationObserver`.
- **تشخیص جهت ورودی (Prompt Composer):** تغییر هوشمند جهت کادر ورودی هنگام تایپ به فارسی یا انگلیسی.
- **دکمه شناور و کلید میانبر:** امکان فعال/غیرفعال‌سازی سریع با کلید میانبر `Ctrl + Shift + R`.
- **پشتیبان‌گیری خودکار (Safety Backup):** ساخت نسخه پشتیبان از فایل اصلی برنامه قبل از اعمال هرگونه تغییر و امکان بازگردانی سریع (Restore).

## 🚀 نحوه نصب و اجرا (Installation)

### روش سریع با Node.js

```bash
# کلون کردن پروژه
git clone https://github.com/MasihBXL/deepai-code-rtl.git
cd deepai-code-rtl

# اعمال پچ روی DeepAI Code
npm run patch
```

### روش اجرایی با فایل دسته‌ای در ویندوز (Batch script)

می‌توانید به راحتی روی فایل `scripts/apply-patch.bat` دابل‌کلیک کنید تا فرایند پچ به‌صورت خودکار اجرا شود.

---

## 🔄 بازگردانی به نسخه اولیه (Restore / Uninstall)

در صورت نیاز به حذف پچ و بازگشت به فایل اورجینال برنامه:

```bash
npm run restore
```

یا فایل `scripts/restore-backup.bat` را اجرا کنید.
