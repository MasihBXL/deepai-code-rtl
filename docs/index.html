پشتیبانی کامل از متن دوزبانه و فونت وزیرمتن

افزودن قابلیت راست‌چین (RTL) به برنامه DeepAI Code

حل مشکل به‌هم‌ریختگی متن‌های ترکیبی فارسی و انگلیسی، جداسازی هوشمند کدها، و نمایش روان پیام‌ها در اپلیکیشن دسکتاپ DeepAI Code.

مشکلاتی که این پچ برطرف می‌کند

  • ترکیب متن فارسی و انگلیسی: رفع مشکل پرش علائم نگارشی (مانند نقطه، پرانتز و علامت سوال) به ابتدای خط هنگام نوشتن کلمات انگلیسی در جملات فارسی.
  • جداسازی کدهای درون‌خطی (Inline Code): واژه‌ها و متغیرهای انگلیسی درون code با حفظ جهت چپ‌به‌راست و ایزولاسیون کامل نمایش داده می‌شوند.
  • حفظ ساختار بلوک‌های کد: تمامی کدهای چندخطی، پنجره‌های Diff، خروجی‌های ترمینال و جداول با جهت LTR باقی می‌مانند.
  • فونت استاندارد وزیرمتن (Vazirmatn): اعمال فونت زیبای فارسی با فاصله خطوط (line-height) بهینه‌شده برای مطالعه راحت.
  • تشخیص خودکار متن ورودی: هماهنگی کامل هنگام تایپ در کادر پرامپت (تغییر جهت خودکار هنگام تایپ فارسی یا انگلیسی).

مقایسه قبل و بعد از اعمال پچ

قبل از پچ (پیش‌فرض LTR)
برای نصب پکیج دستور npm install را در ترمینال بزنید و سپس فایل config.json را ویرایش کنید.
بعد از پچ (RTL با ایزولاسیون)
برای نصب پکیج دستور npm install را در ترمینال بزنید و سپس فایل config.json را ویرایش کنید.

نحوه نصب و استفاده

۱. ریپازیتوری را کلون کرده یا با دستور زیر پچ را اعمال کنید:

# اجرای مستقیم پچ
node src/patcher.js patch

# یا با اجرای فایل scripts/apply-patch.bat

۲. کلید میانبر فعال/غیرفعال‌سازی:

در هر زمان داخل محیط برنامه می‌توانید با فشردن کلیدهای Ctrl + Shift + R یا کلیک بر روی ویجت گوشه صفحه، جهت متن را تغییر دهید.

۳. بازگردانی به نسخه اصلی بدون پچ:

node src/patcher.js restore
